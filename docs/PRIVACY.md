# Privacy

Aquila Radio Astronomy does not collect, store or send any personal information. There is no account, no telemetry, no analytics and no crash reporting.

Everything the app records stays on your computer, in the data folder you choose: spectra, hit tables, plots and the configuration file.

The app uses the network only when you ask it to: when you add a remote node by address, the app fetches that node's files from the address you typed and nothing else. No other connections are made. The source code is public at https://github.com/ayushman-t/aquila-radio-astronomy so this can be checked.
